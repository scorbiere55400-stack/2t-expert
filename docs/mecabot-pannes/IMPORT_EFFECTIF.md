# Import dans 2T Expert

Import du 10 octobre 2026 : 80 fiches canoniques, 28 sources associées, 24 évaluations synthétiques conservées hors recherche documentaire. Empreintes SHA-256 vérifiées avant import. Total de recherche : 106 fiches avec le précédent corpus général.

Toutes les fiches de pannes gardent leur statut non validé en atelier, leurs applications, leur urgence et toutes les sources. La recherche de l’administrateur et le plugin ChatGPT permettent la consultation documentaire de toutes les fiches. Le filtre d'application sert à consulter un domaine, pas à prouver l'applicabilité à un moteur.

Le dialogue MécaBot récupère automatiquement uniquement les principes généraux et les fiches dont toutes les applications appartiennent à moteur 2T, moteur essence 2T ou allumage par bougie. Les fiches spécifiques ne sont pas injectées automatiquement. Les fiches 2T-040 et 2T-041 dépendent d'un PDF inaccessible et restent exclues de la récupération automatique.

Les fiches sont présentées séparément des conclusions guidées. Si un service GPU est configuré ultérieurement, seuls ces documents généraux filtrés alimenteront le contexte de génération. Aucun import dans les poids Qwen, aucun entraînement Colab ni conversion des 24 évaluations en connaissances n'est réalisé.
